# houbu-ticket · 12306 候补购票模拟器

国庆返程抢票策略模拟小游戏：直达票已售罄，你手握 **60 个候补名额**，
在不同"日期+车次"组合之间做分配，看四天兑现期内能不能顺利到家。

> 热点来源声明：灵感来自 2026 年国庆返程季 12306 候补购票"60 个日期+车次组合"
> 攻略在社交平台刷屏。本游戏为**原创虚构**作品，与真实 12306 无任何关联，
> 所有成功率均为拍脑袋虚构数值，不构成任何购票建议。
> 购票请认准**官方唯一渠道 12306**，警惕"内部票""先款后票"骗局。

## 玩法

你有 60 个候补名额，可分配到 4 个组合：

| 组合 | 单名额基础概率 | 代价 |
|---|---|---|
| 10/6 直达高铁 | 3.5%（最低） | 无，到家最早 |
| 10/6 中转（合肥换乘） | 11.5% | 全程约 9 小时 |
| 10/7 直达高铁 | 7% | 多请半天假 |
| 10/5 提前直达 | 15%（最高） | 请 1 天年假 |

模拟推进 4 个轮次（10/4 晚 → 10/5 → 10/6 白天 → **10/6 开车前 20 分钟截止**），
越临近发车兑现概率越低（衰减系数 1.0 → 0.85 → 0.6 → 0.35），截止后不再兑现。

随机事件：

- 🚂 铁路加开临客：新增"10/6 加开临客（绿皮）"组合，附赠 6 个名额
- 📱 深夜兑现短信：凌晨 3 点被短信吵醒——候补成功了，被吵也值
- ⚠️ 黄牛私信"内部票，先款后票"：拒绝并举报才是正解；手滑接受直接翻车+普法

结算称号：**候补之王** / **绿皮车战神** / **请假跑路达人** / **晚到也是到** /
**滞留武汉**（附善意玩梗评语）。

## 运行

纯 Python 标准库，无第三方依赖，Python 3.10+。

```bash
python -m houbu_ticket                 # 交互模式（需要终端）
python -m houbu_ticket --auto --games 10 --seed 42   # AI 自动演示 10 局
python -m houbu_ticket --auto --games 1 --seed 7 --verbose  # 打印每日兑现战报
```

## 诚实局限

- 成功率、衰减系数、事件概率均为虚构调参，与真实 12306 候补机制无关
- AI 分配是固定期望效用公式，不是真正的策略搜索
- 兑现判定为"首个成功即锁定"，未建模多单同时兑现的最优选择
- 文本界面，无图形；倒计时/实时性元素未建模
